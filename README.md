## 掲載作品

### 筋トレ管理アプリ

種目を自由に登録し、部位や細かい分類で記録を管理できるアプリです。
複数セットの入力、自重を含めたボリューム計算、保存データの検証に対応しています。

- 使用技術：React / TypeScript / Vite / CSS / localStorage
- 公開ページ：https://mikiya-web.github.io/workout-app/
- GitHub：https://github.com/mikiya-web/workout-app

現在公開中のV1では、利用中のブラウザにデータを保存します。
Supabaseによる認証・DB保存は、今後のV2で実装する予定です。

### Web制作会社LP

- 使用技術：HTML / CSS / JavaScript
- 公開ページ：https://mikiya-web.github.io/portfolio-corporate-lp/

### フィットネスジムLP

架空のフィットネスジムを想定したランディングページです。
情報を整理し、利用者の行動につながる構成を意識しました。

- 使用技術：HTML / CSS / JavaScript
- 公開ページ：https://mikiya-web.github.io/MORE-ONE-REP/

### 建築会社コーポレートサイト

架空の建築会社を想定したコーポレートサイトです。
企業らしい信頼感を意識し、情報設計・デザイン・コーディングに取り組みました。

- 使用技術：HTML / CSS / JavaScript

## 工夫した点

### 制作物への分かりやすい導線

作品の画像と紹介文から公開ページへ移動できる構成にしました。
筋トレ管理アプリにはGitHubへのリンクも設け、
コードやREADMEから実装内容を確認できるようにしています。

### 画面幅に応じたレイアウト

CSS Gridを使い、制作物をPCでは2列、スマホ幅では1列で表示しています。
自己紹介やスキル欄も画面幅に合わせて配置を切り替えています。

### 操作への配慮

リンクにはキーボード操作時のフォーカス表示を設定しています。
また、動きを減らす端末設定に合わせて、アニメーションを抑えるようにしています。

### Gitを使った変更管理

ブランチで変更を行い、コミット・push後にPull Requestで差分を確認し、
mainへ取り込む流れで更新しています。

## ファイル構成

- `index.html`：ページの構造・紹介文・作品へのリンク
- `style.css`：レイアウト・装飾・レスポンシブ対応
- `image/`：メイン画像・制作物のスクリーンショット
- `README.md`：サイトの概要・確認方法

## ローカルでの確認方法

Gitがインストールされた環境で、以下を実行します。

```bash
git clone https://github.com/mikiya-web/portfolio-link.git
cd portfolio-link
```

取得したフォルダの`index.html`をブラウザで開いてください。
パッケージのインストールやビルドは不要です。
